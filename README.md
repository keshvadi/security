# Computer Network Security

Welcome to the _Computer Network Security_ webbook.

This book is written for undergraduate students in computer science and software engineering. It assumes that readers may have limited prior background in computer networking. For each topic, the minimum networking concepts needed to understand the security material are introduced directly in context, so that the book remains self-contained.

The material is structured across five units:

1. [Unit One](01_introduction/) establishes the core foundations and threat models of computer security.
2. [Unit Two](02_cryptography/) builds the cryptographic primitives and public-key infrastructure necessary for secure communication.
3. [Unit Three](03_network/) applies these concepts to practical domains, focusing on network security.
4. [Unit Four](04_web/) applies these concepts to practical domains, focusing on web security.
5. [Unit Five](05_other-topics/) explores selected topics that fall outside the earlier units but remain essential, including quantum cryptography, AI agents, and cloud security, alongside the critical privacy, legal, and ethical responsibilities that must accompany modern security research and monitoring.

### Acknowledgments

This webbook is an evolution of lecture notes developed for teaching computer network security and software security courses. It was originally developed using four primary resources:

The core logic and structural sequence heavily follow the "Network Systems Security" course taught by [Prof. Joel Reardon](https://cspages.ucalgary.ca/~joel.reardon/) at the University of Calgary, to whom the primary credit for this architecture belongs. Deep, rigorous coverage of each topic was made possible by Paul C. van Oorschot's textbook, _[Computer Security and the Internet: Tools and Jewels from Malware to Bitcoin](https://people.scs.carleton.ca/~paulv/toolsjewels.html)_. In terms of presentation, the interactive webbook format was inspired by [David Wagner](https://people.eecs.berkeley.edu/~daw/) Computer Security course at UC Berkeley. The hands-on ideas were built utilizing the capture-the-flag methodologies provided by the [pwn.college](https://pwn.college/) team.

Beyond these primary sources, the course structure, concepts, and presentation were shaped by reading and research in the network security measurement field, as well as by observing how other research groups teach the subject.
